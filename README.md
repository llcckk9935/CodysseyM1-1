# CodysseyM1-1 — AI 데이터 분석: 시장지표 시계열 트렌드

> **한 줄 소개:** 2021년 10월부터 2026년 9월까지의 여섯 시장지표를 주간 단위로 정리해, 유가·환율·금리의 변화와 국내 휘발유·금·KOSPI의 관계를 분석하고 근거와 한계를 리포트로 설명합니다.

이 프로젝트는 그래프를 만드는 데서 멈추지 않고, **무엇을 관찰했는지(근거)**와 **그 결과를 어떻게 해석할 수 있는지(가설)**를 구분하는 시계열 분석 과제입니다. 전체 분석은 Python 스크립트로 재현하고, 결과는 [REPORT.md](REPORT.md)와 로컬 대시보드에서 확인할 수 있습니다.

## 2. 분석 주제와 질문

### 주제와 선정 이유

국제유가·환율·국고채 3년 금리의 움직임이 국내 휘발유 가격·국제 금·KOSPI와 어떤 관계를 보이는지 살펴봅니다. 시장마다 거래일과 휴장일이 달라 일별 값을 바로 비교하기보다, 실제 관측값으로 일요일 종료 주간 평균을 만들었습니다. 이 분석은 관계와 패턴을 탐색하며 원인·결과를 증명하지 않습니다.

### 분석 질문

1. **Q1 — 유가와 휘발유:** 국제유가가 변한 뒤 국내 휘발유 주간 평균도 움직이는가? 함께 움직이는 시차는 기간에 따라 달라지는가?
2. **Q2 — 환율과 금·KOSPI:** 환율과 금·KOSPI의 장기 가격 수준과 주간 변화는 각각 어떤 관계를 보이는가?
3. **Q3 — 금리와 KOSPI:** 국고채 3년 금리 변화와 KOSPI 변화는 반대 방향으로 움직이는가? 이 관계는 연도별로 안정적인가?

## 3. 데이터와 정제 기준

| 항목 | 내용 |

| 원자료 형식 | `data/raw/`의 CSV·JSON 7개. 이용 조건과 파일 형식은 [DATA_SOURCES.md](DATA_SOURCES.md) 참고 |

### 정제와 품질 확인

- 날짜와 값의 형식을 표준화하고 날짜순으로 정렬합니다. 중복·결측 진단은 전처리 품질 보고서에 남깁니다.
- 주간 평균은 그 주에 실제로 관측된 값만 사용합니다. 빠진 날짜를 보간하거나 임의로 채우지 않습니다.
- 첫 주와 마지막 주는 부분 주간입니다. `*_obs_days` 열에 주간 평균에 포함된 실제 관측일 수를 기록합니다.
- 급격한 주간 변화는 사분위 범위 기준으로 후보를 표시합니다. 후보를 오류라고 단정하거나 삭제하지 않고, 원자료·대표 외부값·민감도 분석을 함께 검토합니다.
- 원자료는 파이프라인에서 수정하지 않으며 실행 전후 SHA-256 해시가 같은지 확인합니다.

세부 진단은 [전처리 품질 보고서](data/processed/preprocessing_quality_report.md), [데이터 검증 기록](DATA_VALIDATION.md), [급변 구간 외부값 대조](EXTREME_SOURCE_CHECK.md)에서 확인할 수 있습니다.

## 5. 핵심 인사이트

아래는 관찰된 수치와 가능한 해석을 구분한 요약입니다. 상세 근거·표본 수·주의점은 [REPORT.md 인사이트](REPORT.md#5-인사이트)에 있습니다.

### 1) 유가와 휘발유의 관계는 시차가 있지만 고정된 시간은 아니다

- **관찰:** 전체 기간 변화율 상관은 동시점 `r=0.1862`, 3주 시차 `r=0.3210`이었습니다. 2022~2025년에는 각 연도에서 1주 시차가 가장 높았고, 2026년 일부 기간에는 3주가 가장 높았습니다.
- **해석:** 유가 변화 뒤 휘발유 변화가 나타나는 듯한 관계는 보이지만, 고정된 반영 시차라고 단정할 수 없습니다. 환율·세금·재고 등 다른 요인을 분리하지 않았습니다.

### 2) 환율과 금·KOSPI는 수준과 주간 변화에서 다른 모습을 보인다

- **관찰:** 전체 가격 수준 상관은 환율·금 `r=+0.7405`, 환율·KOSPI `r=+0.5266`이었습니다. 주간 변화 상관은 각각 `r=-0.3287`, `r=-0.3074`였습니다.
- **해석:** 장기 수준의 동행을 매주 같은 방향으로 움직인다는 뜻으로 읽을 수 없습니다. 공통 시간 추세와 다른 거시 요인이 있을 수 있습니다.

### 3) 금리와 KOSPI의 관계는 연도에 따라 달라졌다

- **관찰:** 전체 금리 변화·KOSPI 변화 상관은 `r=-0.1630`이었습니다. 연도별 상관은 2022년 `-0.4045`, 2023년 `-0.3587`, 2024년 `+0.0483`, 2025년 `+0.3379`, 2026년 일부 기간 `-0.2967`이었습니다.
- **해석:** 전체 평균 관계만으로 특정 연도의 움직임을 설명하기 어렵습니다. 정책·경기·위험 선호 등 다른 요인을 함께 분석하지 않아 원인은 확정할 수 없습니다.

## 9. 실행 방법

### 9-1. 준비물

- Windows와 PowerShell
- Python 3.10 이상 (전체 파이프라인은 Python 3.14.7 개발 환경에서 실행 확인)
- 사용 권한과 이용 조건을 확인한 원자료 7개

공개 저장소에는 원자료와 대시보드 계산 파일 `dashboard/data.json`이 포함되지 않습니다. 먼저 [DATA_SOURCES.md](DATA_SOURCES.md)의 파일명·형식·이용 안내에 따라 파일을 `data/raw/`에 준비하세요. 이미 프로젝트 폴더가 열려 있다면 아래 명령으로 위치를 확인합니다.

```powershell
Get-Location
```

### 9-2. 가상환경 생성

프로젝트 루트에서 명령을 **각 코드 블록마다 하나씩** 위에서 아래로 실행합니다.

```powershell
python -m venv .venv
```

### 9-3. 가상환경 활성화

```powershell
.\.venv\Scripts\Activate.ps1
```

PowerShell 실행 정책 오류가 발생하면 현재 창에서만 다음 명령을 실행하고, 활성화 명령을 다시 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 9-4. 패키지 설치

```powershell
python -m pip install -r requirements.txt
```

### 9-5. 분석 파이프라인 실행

원자료 7개가 있는지 확인하고 실행합니다. 전처리부터 결과 검증까지 차례로 진행됩니다.

```powershell
python scripts/run_pipeline.py
```

완료되면 `data/processed/`, `outputs/`, `dashboard/data.json`이 생성 또는 갱신됩니다. 원자료 해시가 보존되는지도 파이프라인이 확인합니다.

### 9-6. 대시보드 서버 실행

같은 프로젝트 루트에서 서버를 시작합니다. 서버가 실행되는 PowerShell 창을 열어 둡니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory dashboard
```

브라우저에서 [http://127.0.0.1:8765](http://127.0.0.1:8765)를 엽니다. 종료할 때는 서버 창에서 `Ctrl+C`를 누릅니다. HTML 파일을 직접 열면 JSON을 불러오지 못할 수 있어 로컬 서버를 사용합니다.

## 10. 데이터 이용 주의와 한계

- 지표별 출처의 이용 조건과 파일 형식은 [DATA_SOURCES.md](DATA_SOURCES.md)에 정리했습니다. 원자료 재배포 조건이 확인되지 않아 원자료는 GitHub에 올리지 않습니다.
- 국제 금은 Alpha Vantage의 `GOLD_SILVER_HISTORY` 함수, `GOLD`, `daily` 간격으로 제공된 USD/트로이온스 일별 종가입니다. 주말 날짜 값의 시장 기준과 산출 시각은 제공 자료만으로 확인되지 않았습니다.
- 두바이유 급변값의 외부 비교는 같은 평가 기준인지 확인되지 않은 사례가 있어 전체 원자료의 정확성을 확정하지 못합니다. 외부 비교와 미해결 항목은 [EXTREME_SOURCE_CHECK.md](EXTREME_SOURCE_CHECK.md)에 기록했습니다.
- 상관과 시차 상관은 함께 변한 정도를 요약합니다. 인과성이나 미래의 수익·가격을 증명하지 않습니다.
- 분석 기간이 약 5년이어서 계절 패턴의 반복 횟수가 제한적입니다. 월별 패턴을 확정된 계절성으로 해석하지 않았습니다.
- 3주 시차 등 일부 결과는 탐색 범위에서 관찰된 최고값이며, 독립 표본으로 최적성을 검정한 결과가 아닙니다.

## 11. 문제 해결과 관련 문서

| 문제 | 확인할 내용 |
| --- | --- |
| `python` 명령을 찾을 수 없음 | Python 설치 및 PATH를 확인하고 새 PowerShell을 엽니다. |
| 원자료 개수가 맞지 않음 | 7개 파일이 `data/raw/` 바로 아래에 있고 이름·형식이 출처 안내와 일치하는지 확인합니다. |
| 라이브러리 오류 | 프로젝트 루트와 가상환경을 확인한 뒤 아래 설치 명령을 다시 실행합니다. |
| 대시보드에 `data.json` 안내가 표시됨 | 9-5 파이프라인을 성공적으로 실행합니다. |
| 대시보드 주소가 열리지 않음 | 서버 창이 열려 있는지 확인하고 서버를 다시 시작합니다. |

```powershell
python -m pip install -r requirements.txt
```

대시보드 계산을 확인하려면 Node.js를 준비한 뒤 다음 선택 테스트를 실행할 수 있습니다. 이 검사는 브라우저 모양이나 배포 상태를 확인하지 않습니다.

```powershell
node scripts/check_dashboard.cjs
```
